# Early baseline notebook

`baseline.ipynb` is the exploratory notebook preserved from the competition workspace. Execution counts, outputs and widget state have been cleared for publication. It contains several alternative experiments and is not the entry point for the final competition ensemble.

A legacy pooling class and its option key were renamed consistently to `GatedResidualPool` / `xgated` for neutral terminology. Its numerical implementation is unchanged. Use the standalone trainers and the [reproduction guide](../docs/REPRODUCIBILITY.md) for the better-documented workflows.

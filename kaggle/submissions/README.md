# Recovered team inference programs

These files preserve available latest inference source retrieved from the team Kaggle notebooks. Most were archived on 14 October; the late `pseudo5`, `evf5`, `evffold`, `armevf`, `armmr` and `vol3d` programs were refreshed on 6 November 2026.

Exact **scored** notebook versions are linked in [the ledger](../../evidence/submissions.csv). A latest source snapshot is not certified identical to that scored version. Older module docstrings can describe an earlier blend: inspect the current `MEMBERS`, `RETR_MEMBERS`, `NO_STRICT`, TTA flags and checkpoint metadata together.

Programs expect competition inputs and private/historical checkpoints under `/kaggle/input`. They are not a self-contained reproduction of the final score. Several final fold weights, the crop specialist and retrieval database are absent from the confirmed model release. Original authorship belongs to the shared competition work; see [NOTICE](../../NOTICE.md).
